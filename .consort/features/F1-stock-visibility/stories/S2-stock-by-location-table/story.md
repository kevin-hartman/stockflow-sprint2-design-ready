# S2 – Stock-by-location table

**As a** warehouse operator  
**I want to** see a scannable table of stock by location on the home screen  
**So that** I can quickly survey what is on each shelf

## Scope

Home screen renders a table (SKU, location, quantity) for all filed stock. Quantities are right-aligned. When a location has no stock the table shows an explicit "No stock at this location" row — never a blank page.
