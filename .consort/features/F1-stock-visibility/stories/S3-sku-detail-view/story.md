# S3 – SKU detail view

**As a** warehouse operator  
**I want to** view a SKU detail page showing its stock across all locations including the tracking code  
**So that** I can see the full picture for a SKU in one place

## Scope

A SKU detail page lists every location holding that SKU, its quantity, and its inventory_code. Par level (not tracked in V1) shows a clear "not tracked" label — never blank or null. A SKU with no stock shows an explicit empty state.
